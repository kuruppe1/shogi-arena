# stop-slop-jp — AI臭除去ルール(日本語版)

元ネタ: hardikpandya/stop-slop (英語圏で実績のあるAI文体除去スキル)を、
日本語のX投稿向けに翻案したもの。投稿文を書いたら、公開前にこのルールで必ず1回書き直す。

## 禁止パターン(見つけたら書き直し)

### 語彙・言い回し
- 「いかがでしたか」「〜ではないでしょうか」「〜してみてはいかがでしょう」
- 「実は…」で始める(多用禁止。1日の投稿で1回まで)
- 「〜すぎる」「神」「爆速」「最強」「究極」「革命」などの安売り最上級
- 「非常に」「とても」「かなり」「本当に」などの強調副詞 → 削るか具体的な事実に置き換える
- 「〜だけでなく〜も」の二項対比構文
- 「つまり」「要するに」「結論から言うと」の前置き
- 括弧書きの補足(笑)(泣)や、意味のない「…」
- ハッシュタグの乱用(0〜1個まで)

### 絵文字・記号
- 絵文字は1投稿2個まで。行頭の✅🔥💡の連打は禁止
- 「👇」「⬇」で引っ張る誘導は1投稿1回まで
- 全角記号の装飾(★≪≫【】)は【】を冒頭1回のみ許可

### 構造
- 「問いかけ→箇条書き→まとめ」の完全テンプレ充填をそのまま出さない。
  型は使うが、どこか1箇所は崩す(順番を変える、まとめを削る、言い切りで終える)
- 全投稿が同じリズムにならないこと。連続する3投稿で文末表現を重複させない
- 教科書口調(です・ます統一)で通さない。体言止め・言い切りを混ぜる

### 内容
- 検証できない数字を作らない(「9割の人が〜」等の捏造禁止)
- 実在しない商品名・機能を書かない。商品はカテゴリ名か実在の定番品のみ
- 誰でも言える一般論だけの投稿は破棄してネタから選び直す

## 書き直しの手順
1. 生成した投稿文を上のリストと突き合わせ、該当箇所を列挙
2. 該当ゼロになるまで書き直す(最大2回。2回で直らないならネタごと破棄)
3. 最後に音読チェック: 「知人がスマホで打った文章に見えるか?」がYesなら通す
