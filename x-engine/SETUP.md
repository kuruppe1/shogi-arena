# SETUP — あなたが最初に1回だけやること

IFTTTは登録済みとのことなので、残りは以下。上から順にどうぞ。

## 1. Xアカウントを作る (10分)

作成: https://x.com (メールとSMS認証が必要)

### アカウント設計(コピペ用)

- **表示名(推奨)**: `くらしの実験室｜買ってよかったを毎日3つ`
  - 別候補: `ラクする道具箱` / `千円で暮らし変えた人`
- **ID(@ハンドル)**: `@kurashi_labo` (取られてたら `@kurashi_labo3`)
  - 数字の羅列IDは捨て垢感が出て凍結リスクが上がるので避ける
- **プロフィール文(案A・推奨)**:
  > 買ってよかった物と、暮らしがちょっとラクになる小ワザを毎日3つ。全部自分の財布で買って試してから書いてます。ハズレを引いたら正直にハズレと言う派。愛用品はリンクにまとめてます↓
- **プロフィール文(案B)**:
  > ズボラなので「頑張らないで片付く・続く・起きられる」を道具で解決してます。試してよかった物だけ毎日3つ。散財の失敗はみんなの教訓にしてください。
- **アイコン**: Canvaで単色背景+電球や工具のフラットアイコン。顔出し不要。フリー素材の人物写真は禁止(なりすまし誤認)
- **ヘッダー**: 「買ってよかった、だけを毎日3つ。」のテキストだけのシンプル画像。空白はbot感が出るので必ず設定
- **場所**: 空欄でOK
- **生年月日**: 非公開のまま。誤入力で13歳未満扱い→即凍結の事故が多いので慎重に
- **固定ツイート(手動で1回投稿して固定)**:
  > このアカウントは「買ってよかった物」と「暮らしがラクになる小ワザ」を毎日3つ流します。
  > 基準はひとつ、自分で試して続いたかどうか。
  > 続かなかった物は載せません。

### 開設後3日間のウォームアップ(凍結回避)

自動投稿を繋ぐ前に人間の挙動を作る:
- 1日目: プロフィール完成 → 固定ツイート投稿 → 同ジャンルのアカウントを5〜10フォロー
- 2日目: 数件いいね + 手動で1投稿(ネタはClaudeが渡す)
- 3日目: 同上。ここまでやったらIFTTT接続OK

## 2. アフィリエイトに登録する (10分)

おすすめ: **もしもアフィリエイト** (無料・審査ゆるめ・Amazon/楽天両対応)

1. https://af.moshimo.com で無料登録
2. 登録メディアにあなたのXアカウントURLを申請
3. 「Amazon.co.jp」「楽天市場」のプロモーションに提携申請
4. 承認されたら「どこでもリンク」等で紹介リンクを作れる

※Amazonアソシエイト直でもOKだが審査が厳しめ。もしも経由が楽。

## 3. プロフィールにリンクを置く (5分)

1. lit.link等の無料リンクまとめページに、もしもの紹介リンクを並べる
2. Xプロフィールの「ウェブサイト」欄にそのURLを設定
3. 投稿が伸びる → プロフィールが見られる → リンクが踏まれる、が収益の流れ

## 4. IFTTTのAppletを作る (5分) ※アカウントは登録済み

1. 「Create」から新しいApplet:
   - **If This**: 「RSS Feed」→「New feed item」
   - Feed URL:
     ```
     https://raw.githubusercontent.com/kuruppe1/shogi-arena/main/feed.xml
     ```
   - **Then That**: 「Twitter」(X) →「Post a tweet」
   - Tweet text: `{{EntryContent}}` を指定(改行が保持される。{{EntryTitle}}は改行が消えるので使わない)
2. Xアカウントとの連携を許可して保存

※無料プランはRSSチェックが約1時間ごと。投稿時刻が多少ズレるが問題なし。

## 5. 完了をClaudeに伝える

1〜4が終わったらセッションで「セットアップ終わった」と言う。
Claudeが定期実行(Routine)を仕込んで全自動運転が始まる。
