# x-engine — X投稿 自動生成エンジン

テーマ: 便利グッズ・暮らし改善(QOL)
収益導線: 価値投稿で拡散 → プロフィールのアフィリエイトリンク(もしも/Amazon) → 商品購入で報酬

## 全体の流れ

```
定期実行でClaudeが起動
  ├ topics.md からネタを選ぶ(未使用のもの)
  ├ templates.md のバズ型5種をローテーションで適用
  ├ .claude/skills/stop-slop-jp/SKILL.md でAI臭を除去(必須工程)
  ├ feed.xml に新規投稿を追記して push
  └ log.md に記録
        ↓ (GitHubが自動公開)
feed.xml のRSS
        ↓
IFTTT「RSS新着 → Xに投稿」applet が自動投稿
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `README.md` | この文書。全体像 |
| `SETUP.md` | あなた(人間)が最初に1回だけやる作業の手順書 |
| `RUNBOOK.md` | 定期実行のClaudeが毎回従う作業指示書 |
| `templates.md` | バズ型テンプレート5種 |
| `topics.md` | ネタ帳(使ったら消し込み) |
| `log.md` | 投稿履歴と使用テンプレの記録 |
| `/feed.xml` | IFTTTが読むRSSフィード(リポジトリ直下) |

## 運用ルール

- 1日3投稿。それ以上は増やさない(スパム判定・凍結リスク)
- 投稿は全角135文字以内(Xの140字制限に余裕をもたせる)
- 投稿本文に外部リンクは入れない(Xはリンク付き投稿の表示を抑制するため)。収益はプロフィールのリンク経由
- 検証できない数字・実在しない商品は書かない
- 反応データの改善ループ: 運用開始2週間後から、伸びた投稿の型を log.md に記録し、型の出現比率を調整する
