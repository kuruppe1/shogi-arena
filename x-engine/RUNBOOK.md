# RUNBOOK — 定期実行のClaudeへの作業指示書

この指示書は、定期実行(Routine)で起動したClaudeが毎回従うもの。
1回の実行で生成する投稿は「1つだけ」。
(理由: IFTTTは新着を検知した分まとめて投稿するため、複数追加すると連投になり不自然。
 1日3回の実行×1投稿=1日3投稿のペースを作る)

## 手順

### 1. 状態の読み込み
- `x-engine/log.md` を読み、直近の使用テンプレ型と直近3投稿の本文を確認する
- `x-engine/templates.md` のローテーション規則で今回の型を決める
- `x-engine/topics.md` から未使用(`- [ ]`)のネタを1つ選ぶ。型との相性で選んでよい

### 2. 生成
- 選んだ型の構造でネタを投稿文にする
- 制約: 全角135文字以内 / リンク・ハッシュタグなし / 絵文字2個まで / 捏造数字・架空商品の禁止

### 3. AI臭の除去(必須・省略禁止)
- `.claude/skills/stop-slop-jp/SKILL.md` を読み、A(削る)→B(足す)→C(3問判定)を実行する
- log.md の直近3投稿と文末・リズムが被っていないか確認する。被っていたら書き直す
- Cで2回書き直しても合格しない場合、そのネタは破棄して別のネタで最初からやり直す

### 4. RSSへの反映
- リポジトリ直下の `feed.xml` を編集:
  - `<channel>` 内の先頭(既存itemの上)に新しい `<item>` を追加
  - `<title>`: 本文の1行目(30字程度で切ってよい)
  - `<description>`: `<![CDATA[ ]]>` で本文全文(改行そのまま)
  - `<link>`: `https://github.com/kuruppe1/shogi-arena/blob/main/x-engine/log.md#post-NNNN`
    (IFTTTはitemにlinkが無いとフィードを無効扱いにするため必須。投稿本文には使われない)
  - `<guid isPermaLink="false">`: `post-NNNN` (連番をインクリメント)
  - `<pubDate>`: 現在時刻(RFC822形式。`date -R` で取得)
  - `<lastBuildDate>` も現在時刻に更新
  - item数が20を超えたら、一番古いitemを削除する

### 5. 記録
- `x-engine/log.md` に行を追加: 日付 / guid / 型 / ネタ / 本文
- `x-engine/topics.md` の使ったネタを `- [x]` にして `(→post-NNNNで使用)` を付記
- topics.md の未使用在庫が10個未満なら、topics.md末尾の補充ルールに従いWeb検索で5個以上補充する

### 6. コミットとプッシュ
- 変更をコミットしてプッシュする(メッセージ例: `Add post-0004 to feed`)
- プッシュ先は現在の作業ブランチ(PRマージ後はmain)

## 改善ループ(運用開始2週間後から)

ユーザーから反応データ(伸びた投稿・伸びなかった投稿)の共有があったら:
- log.md に「反応メモ」列を追記し、伸びた型の出現比率を上げるようローテを調整する
- 伸びた投稿の構造的な特徴(文頭フック/行数/具体度)を templates.md に反映する
- ユーザーからデータ共有がない間は、勝手に方針を変えない(型のローテを守る)

## 禁止事項

- 1回の実行で2投稿以上追加しない
- stop-slop-jpの工程を飛ばさない
- 医療・健康効果の断定、金融アドバイス、特定個人・企業への言及をしない
- feed.xml のXML構造を壊さない(編集後に整形式かを確認する)
