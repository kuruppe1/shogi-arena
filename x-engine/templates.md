# templates.md — バズ型テンプレート6種

Xで実証されている「知識・共感・意外性・意見・まとめ・解決」の6型を、
便利グッズ・暮らし改善テーマに合わせたもの。

⑥は`x-engine/RESEARCH.md`の実データリサーチ(2,722件・2,015アカウント調査)で見つかった
再現性のある型を反映したもの。①〜⑤も同リサーチで裏付けが取れている。

## 使い方(ローテーション規則)

- 1投稿につき1型。直近の使用型は log.md に記録されている
- 基本ローテ: ① → ② → ③ → ④ → ⑤ → ⑥ → ①… の順で回す
- ただし完全な機械順は避ける。同じ型が2回続かなければ、ネタとの相性で前後入れ替えてよい
- どの型でも、テンプレを充填したまま出さない。stop-slop-jpのルールに従い必ず1箇所崩す

## ① 意外性型「常識の否定」

```
構造: みんなが信じてる常識 → 否定 → 本当の原因/正解
狙い: 「え、そうなの?」→ 保存・拡散
```

例:
> 「電源タップは床に置くもの」と思われがちですが、それだと机の上のケーブルは結局垂れ下がって絡まります。
> 卓上型にして手の届く位置に固定すると、ケーブルの重さが下に逃げず定位置に収まります。
> 散らかる原因は物の量ではなく、電源までの距離でした。

## ② まとめ型「厳選リスト」

```
構造: 絞り込みフック(価格帯/場面) → 3点リスト → 共通点を一言
狙い: リストは保存率が最も高い
注意: 「神アイテム3選!」のような煽り見出しは禁止。フックは具体で絞る
リサーチでの裏付け: 「素材A×素材B」のような組み合わせ形式の5選(例:「サーモン×梅干しの魚料理5選」)が
複数回安定して反応を得ていた。3点固定にこだわらず、組み合わせが効くネタなら5選にしてよい
```

例:
> 評判のいい千円以下の時短グッズ
> ・ケーブルバンド(コードの色ごとに束ねると抜き挿しで迷わない)
> ・キーボード掃除のスライム(隙間に押し込むだけで奥のゴミまで取れる)
> ・玄関の鍵置きトレー(鍵を使う手の高さに合わせると置き忘れが減る)
> 共通してるのは、探す・迷う時間を減らす道具ということ。

## ③ 共感型「悩み→解決」

```
構造: あるある悩みの提示 → 意外に小さい解決策 → 自分の変化
狙い: 「私もそれ」→ RT。悩みが深いほど伸びる
```

例:
> 朝起きられない人は目覚ましを増やすより、カーテンを10cmだけ開けて寝るほうが効きます。
> 全開だと眩しくて眠りが浅くなりますが、10cmなら朝方の光量だけ自然に入ってきます。
> 音で無理に起こすより、体内時計に合わせて起きる方が楽です。

## ④ 知識型「一段上の使い方」

```
構造: みんなが持ってる物 → 知られてない使い方/選び方 → 効果の実感
狙い: 「持ってるのに知らなかった」は刺さりが深い
```

例:
> 突っ張り棒は横より縦に使うと収納力が上がります。
> 棚板の間に立てて設置すると、平置きでは倒れる物も仕切りとして支えられます。
> 100均の2本を、棚の奥行きに合わせて突っ張るだけで作れます。

## ⑤ 問いかけ型「二択クイズ/どっち派」

```
構造: 二択の問い → 意外な答えか、答えを委ねる → 会話の種
狙い: リプ・引用を誘発してアルゴリズムに乗る
注意: 5型の中で唯一「答えを言い切らない」ことが許される型
```

例:
> 洗濯物、「乾いたら畳む」のやめた人いる?
> 洗濯バサミ付きハンガーのまま、クローゼットの空いてる場所に直接掛けると、畳む工程がまるごとなくなります。
> 畳む派の理由、逆に聞きたい。

## ⑥ 解決型「困りごと→身近な物→手順」

```
構造: 具体的な困りごとの提示 → 身近にある物での解決策 → 簡単な手順
狙い: リサーチで最も反復して高反応だった型(官公庁の防災アカウント等が繰り返し使用)。
     押しつけがましくない「〜してみてください」「〜すると解決します」口調が特徴
注意: このアカウントは公的機関でも専門家でもないので、「私たちが検証した」といった
     信頼性の詐称はしない。ただし「らしい」等のヘッジ語を貼り付ければ免罪符になるわけではない。
     信頼性は権威の詐称でも伝聞調でもなく、具体性の解像度(何を・どこに・どう、の手順の細かさ)で出す
```

例:
> ビニール袋の口、結べなくて困ることがあります。
> 紐を使うと簡単に結べますが、ポイントはナイロン製の紐でなるべく上の方を縛ることです。上の方だと空気が抜けにくく、水のうを作る時にも使えます。
> 特別な道具はいりません。

## 商品紹介枠「1日1回・リンクあり」

①〜⑥のローテとは別枠。固定ツイートで「良かった商品も紹介します」と宣言しているため、
1日3投稿のうち1つはこの枠を使う。

```
構造: ①〜⑥のどれかで扱った/扱う予定のネタに関連する商品をAmazonで検索し、紹介する
制約:
- 商品ページ直リンクは廃番でリンク切れするため、検索結果リンクにする(kurashilabo3-22のIDを付与)
- 本文に「#PR」または「アフィリエイトリンクを含みます」を明記する(ステマ規制対応)
- リンクを含むためXの表示抑制を受ける前提。無理にバズらせようとせず、
  プロフィール流入済み・購入意欲のある層への直接提示が目的
- ①〜⑥と同じく一人称の虚偽体験談は書かない
```

例:
> 桶を逆さに掛けて浮かせるなら、耐荷重は表示よりやや余裕を持たせて選ぶと安心です。
> 種類が多いので、探すときの参考にどうぞ→(検索結果リンク)
> #PR

## 1日の投稿配分

- 3投稿/日のうち **2つは①〜⑥ローテ(リンクなし)、1つは商品紹介枠(リンクあり)**
- 商品紹介枠は毎日同じ時間帯に固定せず、①〜⑥のどこかの直後に挟む形でよい
- 直近の使用枠は log.md に記録する

## 全型共通の制約

- 全角135文字以内(改行含む)
- 投稿本文にリンク・ハッシュタグを入れない(プロフィール誘導で収益化する設計のため。商品紹介枠を除く)
- 実在しない商品・捏造した数字は書かない
- 絵文字は2個まで(使わなくてよい)
- **一人称の体験談(「買った」「試した」「やってみた」「〜だった」と言い切る形)を書かない。実際に本人が購入・試用した事実がないため**
- **「らしい」「〜んだとか」等のヘッジ語は多用しない。ヘッジは免罪符にならず、貼り付けるほど取ってつけた印象(AI臭さ)が増す。本当に検証不能な主観的結果の話にだけ最小限使い、物理的・論理的に自明な因果関係にはヘッジ不要**
- **一般論・誰でも知ってる内容で終わらせない(最重要)**: 「〜すると解決します」だけでなく、
  なぜ今まで実行できなかったのか(手間・動作の数・忘れる仕組み)と、その障壁を取り除く具体的な仕組みまで書く。
  道具名や場所の紹介だけで終わらせず、「どこに・どう置く/使う」の解像度まで踏み込む
- リサーチで確認: レシピ系の反復アカウントは「【レンジで簡単】【○○】」のような**定型の書き出しタグ**を毎回使っていた。認知の蓄積に効くので、型によっては冒頭に軽い定型フレーズ(例:「今日の小ワザ:」)を試してもよい。ただし毎回同じだとテンプレ感が出るので、①〜⑥のどれかでのみ使う等、乱用しない
- 「人間らしさを出そう」と意図的な感想・気取った結び(「〜、と。」等)を足すと逆に不自然になりやすい。実例(公的機関アカウント等)は感想を足さず淡々と情報を書いて終えている。無理に人間味を足すより、実例の言い回しを直接借りる方が自然になる
