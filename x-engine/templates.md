# templates.md — バズ型テンプレート5種

Xで実証されている「知識・共感・意外性・意見・まとめ」の5型を、
便利グッズ・暮らし改善テーマに合わせたもの。

## 使い方(ローテーション規則)

- 1投稿につき1型。直近の使用型は log.md に記録されている
- 基本ローテ: ① → ② → ③ → ④ → ⑤ → ①… の順で回す
- ただし完全な機械順は避ける。同じ型が2回続かなければ、ネタとの相性で前後入れ替えてよい
- どの型でも、テンプレを充填したまま出さない。stop-slop-jpのルールに従い必ず1箇所崩す

---

## ① 意外性型「常識の否定」

```
構造: みんなが信じてる常識 → 否定 → 本当の原因/正解
狙い: 「え、そうなの?」→ 保存・拡散
```

例:
> 延長コードを変えるだけで机が片付くって、最初は嘘だと思ってた。
> 電源タップを卓上型にすると充電ケーブルが定位置に収まるらしい。
> 散らかりの原因は物じゃなくて、電源の位置みたい。

## ② まとめ型「厳選リスト」

```
構造: 絞り込みフック(価格帯/場面) → 3点リスト → 共通点を一言
狙い: リストは保存率が最も高い
注意: 「神アイテム3選!」のような煽り見出しは禁止。フックは具体で絞る
```

例:
> 評判のいい千円以下の時短グッズ
> ・ケーブルバンド
> ・キーボード掃除のスライム
> ・玄関の鍵置きトレー
> どれも地味。でも「探す時間」が消えるらしい。

## ③ 共感型「悩み→解決」

```
構造: あるある悩みの提示 → 意外に小さい解決策 → 自分の変化
狙い: 「私もそれ」→ RT。悩みが深いほど伸びる
```

例:
> 朝起きられない人は目覚ましを増やすより、カーテンを10cm開けて寝るほうが効くらしい。
> 光で起きると音より体が楽なんだとか。
> 試した人の話だと、1週間で目覚まし2個には戻れなくなるらしい。

## ④ 知識型「一段上の使い方」

```
構造: みんなが持ってる物 → 知られてない使い方/選び方 → 効果の実感
狙い: 「持ってるのに知らなかった」は刺さりが深い
```

例:
> 突っ張り棒、縦に使うと洗面所の収納が倍になるらしい。
> 棚の間に立てて仕切りにするだけ。
> 100均の2本、10分あればできるみたい。

## ⑤ 問いかけ型「二択クイズ/どっち派」

```
構造: 二択の問い → 意外な答えか、答えを委ねる → 会話の種
狙い: リプ・引用を誘発してアルゴリズムに乗る
注意: 5型の中で唯一「答えを言い切らない」ことが許される型
```

例:
> 洗濯物、「乾いたら畳む」のやめた人いる?
> ハンガーのまま掛ける収納にすると、畳む時間がゼロになるらしい。
> 畳む派の理由、逆に聞きたい。

## 全型共通の制約

- 全角135文字以内(改行含む)
- 投稿本文にリンク・ハッシュタグを入れない(プロフィール誘導で収益化する設計のため)
- 実在しない商品・捏造した数字は書かない
- 絵文字は2個まで(使わなくてよい)
- **一人称の体験談(「買った」「試した」「やってみた」「〜だった」と言い切る形)を書かない。実際に本人が購入・試用した事実がないため。「らしい」「〜んだとか」「話題になってる」等、伝聞・キュレーションと分かる語尾を使う**
